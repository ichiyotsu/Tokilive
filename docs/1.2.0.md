# tokilive 1.2.0

三个平台使用同一个版本号。

| 平台 | 版本 |
| --- | --- |
| Windows `package.json` | 1.2.0。安装包文件名是 `tokilive-1.2.0-setup.exe` 和 `tokilive-1.2.0-portable.exe`。 |
| Android `versionName` | 1.2.0。`versionCode` 为 3（1.0.0 是 1，1.1.0 是 2）。应用 ID 仍是 `com.ichiyotsu.tokilive`。 |
| iOS / iPadOS | `CFBundleShortVersionString` 1.2.0，`CFBundleVersion` 3。Bundle ID 仍是 `com.ichiyotsu.tokilive`。 |

应用内更新用数字比较：1.2.0 新于 1.1.0，相同版本不会提示更新。1.0.0 和带私人仓库授权的 1.1.0 需要手动安装 1.2.0 一次。
