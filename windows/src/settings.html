窗口捕获

两个悬浮窗的标题分别是「tokilive · 弹幕」和「tokilive · 实时窗」，设置窗口是「tokilive · 设置」。它们会出现在任务栏里，是为了去掉工具窗口样式，让 OBS 和直播姬的窗口列表能分开枚举。透明本身仍是分层窗口，传统 BitBlt 捕获通常仍是黑的或捕不到。没有在这台环境里用真实的 OBS 或直播姬核对过画面。

OBS 浏览器源

这是保持透明的捕获办法。浏览器源不走窗口捕获。直播姬如果支持浏览器源，使用同一对地址。宽度和高度按你的悬浮窗来，勾选自定义 CSS 并允许透明背景。

歌词（测试）

读取 Windows 系统媒体会话，优先标出 QQ 音乐和网易云。不读取播放器自己的数据库，也不注入进程。歌词来自你导入的 LRC，或公开的 LRCLIB。没有时间轴就不会假装有逐字时间。

关于

 
tokilive
版本 1.2.0设置页按 WinUI 的导航、间距和焦点来排，运行时仍是 Electron，不是原生 WinUI 3。

 
1.0.0 和 1.1.0 需要手动安装 1.2.0 一次。之后从公开的 Releases 更新。

 
语音使用 Chromium 自带的 Web Speech API 和系统语音，没有再打包语音引擎。各系统语音的许可跟随操作系统。

 
字体仍内置 Google Sans、思源黑体、Inter、One UI Sans、苹方。体积主要来自 Electron 运行时和这些字体，没有为了变小删掉可选字体。
